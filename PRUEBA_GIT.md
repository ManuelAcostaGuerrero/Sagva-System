# Prueba de Git

Este archivo fue creado para comprobar el flujo de actualización, commit y push de Sagva-System.

## Instrucción de prueba

1. Ejecuta `git pull origin main`.
2. Abre este archivo.
3. Agrega una línea debajo que diga: `Prueba realizada correctamente`.
4. Guarda el archivo.
5. Ejecuta `git add PRUEBA_GIT.md`.
6. Ejecuta `git commit -m "Prueba de commit local"`.
7. Ejecuta `git push origin main`.
